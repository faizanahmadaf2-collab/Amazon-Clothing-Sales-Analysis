This project aims at analyzing clothing products for different brands on Amazon. The dataset includes product details, pricing, customer demographics, payment methods, review ratings, and delivery times.

The dataset contains 20,000+ clothing sales records from Amazon, covering Men’s, Women’s, Kids’, and Baby categories. Data was extracted from publicly available product pages, seller listings, and transactional overlays. Each record includes product attributes, pricing and discount metrics, customer demographics, purchase details, and device usage information.
